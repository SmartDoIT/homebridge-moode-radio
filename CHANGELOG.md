# Changelog

## 0.4.3
- Default accessory name is "moOde Radio".

## 0.4.1
- Declare the ConfiguredName characteristic on the station switches (no more warnings in the Homebridge log).

## 0.4.0
- One accessory with one switch per station, instead of one accessory per station. Accessories from older versions are removed at startup.

## 0.3.0
- Removed the refresh switch; favourites are read from moOde when Homebridge starts.

## 0.2.0
- Removed the stop switch and the scheduled rescan. Turning off the playing station's switch stops the music.

## 0.1.0
- First version: switches for moOde favourites.
